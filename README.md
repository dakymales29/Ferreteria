# 🛠️ Sistema de Gestión Integral - Ferretería Don Villa

Aplicación web full stack diseñada a medida para automatizar y optimizar la administración completa de **Ferretería Don Villa**. Permite controlar desde el stock de productos, cálculo automático de impuestos (IVA) e importación masiva desde Excel, hasta el registro en tiempo real de ventas, compras a proveedores y gestión de personal.

---

## 🚀 Tecnologías utilizadas

### 🔧 Backend
- **Node.js** & **Express** (API REST robusta y estructurada)
- **PostgreSQL** hospedado en **Neon.tech** (Base de datos relacional serverless en la nube)
- **Manejo de archivos Excel** (Procesamiento de plantillas `.xlsx` / `.csv`)
- **Dotenv** (Manejo seguro de credenciales y variables de entorno)

### 🎨 Frontend
- **Vue.js 3** con **Vite** (Interfaz SPA ultrarrápida)
- **Tailwind CSS** (Diseño moderno, limpio y responsive)
- **Vue Router** (Navegación fluida entre módulos)

---

## ⚙️ Funcionalidades principales

- 📊 **Carga e Importación Masiva (Excel):** Módulo para subir inventarios completos mediante hojas de cálculo Excel (`.xlsx`), agilizando la creación y actualización de productos.
- 📦 **Control de Inventario y Stock:** Registro, edición y monitoreo de productos con control de existencias en tiempo real.
- 💰 **Punto de Venta (Ventas):** Facturación rápida con cálculo automático de precios, subtotales e **IVA configurable**.
- 📥 **Gestión de Compras:** Módulo para ingresar mercadería de proveedores y actualizar el inventario automáticamente.
- ⚙️ **Configuración del Sistema:** Panel centralizado para ajustar parámetros globales del negocio (porcentajes de IVA, datos de la ferretería, etc.).
- 👥 **Módulo de Usuarios & Autenticación:** Control de accesos seguro para administradores y empleados.
- 📱 **Diseño Responsive:** Interfaz adaptada para trabajar cómodamente desde PC de escritorio o tablets en el local.
